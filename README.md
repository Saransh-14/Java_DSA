# ☕ Java Data Structures & Algorithms (DSA)

A organized repository containing foundational and advanced **Data Structures and Algorithms** implementations written in clean, modular **Java**. This repository serves as a learning journal and interview preparation guide covering fundamental concepts, problem-solving techniques, and custom data structure implementations.

---

## 📌 Repository Structure & Topics Covered

The codebase is structured into topic-specific directories containing raw implementations, custom data structures, and practice problem solutions:

### 1. 🔢 Arrays & Matrices (`/Arrays`)
* **Basics & Operations:** Array initialization, element insertion, deletion, and basic traversal.
* **Array Manipulation:** Array reversal, two-pointer techniques, and sub-array patterns.
* **Searching & Sorting:** Binary search implementations and basic sorting algorithms (Bubble, Selection, Insertion).
* **2D Arrays & Matrices:** Matrix traversal and multi-dimensional array operations.

### 2. 🔍 Searching Algorithms (`/Searching`)
* **Binary Search Variants:** Standard Binary Search, slope-based binary search, and searching in rotated sorted arrays.
* **Index Range Search:** First and last occurrence index finding.
* **Problem Sets:** Complex multi-pointer and search optimization problems.

### 3. 🧵 String Operations (`/String`)
* String manipulations, character frequency analyses, and built-in Java string methods exploration.

### 4. 🔗 Custom Linked List (`/LinkedList`)
* **Custom LinkedList Implementation:** Built from scratch using custom node classes (`Node`).
* **Core Operations:** Node insertion, deletion, reversal, and traversal methods.

### 5. 🥞 Custom Stack (`/Stack`)
* **Custom Stack Implementation:** Array/Node-based LIFO data structure implementation.
* **Stack Problems:** Expression evaluation, element tracking, and algorithmic stack challenges.

### 6. 📥 Custom Queue (`/Queue`)
* **Queue & Circular Queue Implementations:** Custom FIFO implementations.
* **Queue Problems:** Array/Linked-list backed queues and practice problems.

### 7. 🔄 Recursion & Backtracking (`/Recursion`)
* **Recursion Basics:** Base-case identification, call-stack tracing, and recursive mathematical functions.
* **Recursion on Strings & Arrays:** Subsequences, permutations, and pattern generation.
* **Divide & Conquer:**
  * **Merge Sort:** $O(N \log N)$ Divide-and-Conquer sorting algorithm.
  * **Quick Sort & Quick Select:** Pivot-based partitioning and selection algorithms.
* **Backtracking:** Maze traversal, N-Queens/N-Knights style decision-tree state exploration.
